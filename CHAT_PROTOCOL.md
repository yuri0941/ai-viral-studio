## ❌ ЧТО НЕ ПРИСЫЛАТЬ (AI уже знает / лежит в репозитории)

| Файл / Данные | Почему не нужно | Где взять AI |
|---------------|-----------------|--------------|
| `PROGRESS_REPORT.md` целиком | Лежит в `D:\kilo2\`, AI читает через `@file` | Пришли **только последние 20-30 строк** (где остановились) |
| `PROJECT_CONTEXT.md` | В репозитории, AI помнит архитектуру, роли, эндпоинты | Не присылай |
| Старые промпты v1–v7 | Уже выполнены, неактуальны | Не присылай |
| Скриншоты логов | AI не видит картинки | Копируй **текст** (3–5 строк ошибки) |
| `node_modules/`, `dist/`, `.git/` | Системные папки | Никогда не присылай |
| Весь `server.js` (1000+ строк) | Если ошибка импорта — достаточно начала | Пришли **только строки 1–80** (где импорты) |
| Весь `OmegaChat.jsx` | Если баг скролла — достаточно className | Пришли **только строки с className** |
| Весь `ru.json` / `en.json` | Если i18n баг — достаточно секции | Пришли **только секцию** (например, `"chat": {...}`) |

## ✅ ЧТО ПРИСЫЛАТЬ (по ситуации)

| Ситуация | Что прислать | Формат |

| **Kimi зависла / не создала файл** | Название файла + что она написала в ответе | `Завис на шаге X, файл Y не создан` |
| **Новый баг после deploy** | Шаги воспроизведения + текст ошибки | 1–2 предложения |
| **Хочу новую фичу** | Описание 1–2 предложения | `Добавь: [описание]` |
| **Готов к следующему этапу** | Напиши статус | `Готов к v9.0-ARCH` |

## ⚠️ ПРАВИЛА РАБОТЫ С KIMI VS CODE

1. **Не перезапускай** если прошло менее 15 минут — Kimi думает
2. **Перезапусти** если прошло 15+ минут и полная тишина (терминал пустой, чат пустой)
3. **Не трогай** окно Kimi VS Code во время работы промпта — прервёшь прогресс
4. **Проверяй** `node --check` и `npm run build` после каждого шага — не жди финала
5. **Git commit** после каждого этапа — `git add . && git commit -m "vX.X шаг Y"`

## 📞 ЭКСТРЕННЫЕ СЛУЧАИ

| Проблема | Что делать |
|----------|------------|
| Kimi VS Code завис на 20+ минут | Закрой вкладку → открой новую → вставь продолжение с шага X |
| Render падает после deploy | Проверь логи → пришли AI 5 строк ошибки → получи HOTFIX |
| `npm run build` падает | Пришли последние 20 строк → AI найдёт ошибку |
| OMEGA Chat не отвечает | Проверь роль (owner = безлимит) → пришли лог backend |
| Забыл на каком этапе | Открой `PROGRESS_REPORT.md` — там всё записано |
