## 1. 💰 ГИБКОЕ УПРАВЛЕНИЕ ТАРИФАМИ (Owner Dashboard)

### 1.1 Редактирование стоимости тарифов в реальном времени
**Где:** Владелец → Подписки → "Управление тарифами"

**Функционал:**
- Таблица всех тарифов: Free, Creator, Pro, Agency, Enterprise
- Поля для редактирования:
  - `basePrice` — базовая цена (₽/$/€)
  - `yearlyDiscount` — скидка за год (по умолчанию -20%)
  - `generationLimit` — лимит генераций
  - `features` — список включённых функций (чекбоксы)
  - `isActive` — включён/выключен тариф
  - `isPublic` — виден на лендинге / скрыт (для VIP/бета)
  - `trialDays` — дни триала (0 = без триала)
- История изменений цен: кто, когда, старое/новое значение
- A/B тестирование цен: "Показывать цену A 50% пользователей, цену B — 50%"
- Авто-уведомление клиентов при повышении цены (за 30 дней)

**Backend:**
- `PUT /api/admin/subscription-plans/:id` — обновление тарифа (только owner/admin)
- `POST /api/admin/subscription-plans` — создание нового тарифа
- `GET /api/admin/subscription-plans/history` — история изменений
- Модель `SubscriptionPlan` — добавить поля: `isActive`, `isPublic`, `trialDays`, `abTestVariant`

**Frontend:**
- `SubscriptionPricingTab.jsx` — таб в Owner Dashboard
- Drag-and-drop сортировка тарифов
- Preview: как выглядит на лендинге
- Кнопка "Сохранить и применить" / "Сохранить черновик"

### 1.2 Промо-акции и купоны
**Где:** Владелец → Подписки → "Промо-акции"

**Типы промо:**
- Процентная скидка (-30% на первый месяц)
- Фиксированная скидка (-500₽)
- Дополнительные генерации (+100 бесплатно)
- Расширенный триал (14 дней вместо 7)
- Реферальный код (персональный)

**Правила:**
- Срок действия (от/до)
- Лимит использований (100 штук)
- Применимость к тарифам (только Pro+, все кроме Free)
- Stackable: можно комбинировать с годовой скидкой — да/нет

**Backend:**
- Модель `PromoCode` (code, type, value, validFrom, validTo, usageLimit, usedCount, applicablePlans)
- `POST /api/promo/validate` — проверка кода при оформлении
- `POST /api/promo/apply` — применение кода

**Frontend:**
- Поле "Промокод" при оформлении подписки
- Авто-проверка: валиден/невалиден/истёк/исчерпан
- Отображение экономии: "Вы экономите 500₽"

### 1.3 Динамическое ценообразование (Smart Pricing)
**Автоматические правила:**
- Если конверсия в Pro < 5% → авто-понижение цены на 10% на 7 дней
- Если загрузка серверов > 90% → приостановить скидки
- Сезонность: летом -10% на Agency (малый бизнес в отпуске)
- Новый клиент: первый месяц -50% (триггер: регистрация)

## 3. 👤 КЛИЕНТСКИЙ ОПЫТ (UX)

### 3.1 Smart Onboarding v2 (улучшенный)
**Текущий:** 5 шагов (ниша → соцсети → стиль → подключение → первый пост)

**Улучшения:**
- **Шаг 0 — Welcome Screen**: анимированное intro (3 слайда: "Создавай", "Анализируй", "Публикуй")
- **Шаг 1 — Ниша**: не просто dropdown, а AI-поиск: начни печатать "коф..." → "Кофейня", "Кофе-машины", "Кофе онлайн"
- **Шаг 2 — Соцсети**: визуальные иконки-плитки с toggle, подсветка рекомендуемых ("Для кофеен чаще всего выбирают Instagram + TikTok")
- **Шаг 3 — Стиль**: не текст, а примеры постов:
  - [Профессиональный] — "Откройте для себя аромат..."
  - [Дружелюбный] — "Привет! У нас новый латте ☕"
  - [Ироничный] — "Когда кофе закончился, но ты не сдаёшься"
  - Клиент выбирает → OMEGA показывает 3 примера в этом стиле
- **Шаг 4 — Подключение**: OAuth кнопки (Instagram, TikTok, YouTube, Telegram, VK)
  - Если нет аккаунта — кнопка "Пропустить, сделаю позже" (не блокирует)
  - Прогресс-бар с анимацией подключения
- **Шаг 5 — Первый пост**: OMEGA генерирует 3 варианта → карусель превью
  - Кнопки: "Запланировать", "Отредактировать", "Сгенерировать ещё"
  - После публикации: конфетти-анимация + бейдж "First Post!" + 50 бонусных генераций

**Прогресс сохранения:** если клиент закрыл onboarding на шаге 3 — при следующем входе продолжает с шага 3

## 4. 🤖 OMEGA ДЛЯ КЛИЕНТА (улучшения)

### 4.1 Контекстуальная память (Client Memory)
OMEGA помнит для КАЖДОГО клиента:
- Ниша, стиль, предпочитаемые соцсети
- Лучшие посты (по просмотрам)
- Худшие посты (чего избегать)
- Частые запросы ("мне нужны хуки для кофе")
- Время активности (когда клиент обычно заходит)
- Бюджет и лимиты (не предлагать Pro если на Free)

**Результат:** OMEGA не спрашивает "Какая у вас ниша?" каждый раз — она ЗНАЕТ.

### 4.2 Проактивные действия (Proactive OMEGA)
OMEGA сама пишет клиенту (push/email/in-app):
- "В вашей нише сейчас тренд [X]. Я подготовила пост — одобрите?"
- "Ваш конкурент @brand опубликовал вирусный Reels. Вот адаптированная версия для вас"
- "Завтра праздник — я подготовила поздравительный пост"
- "Ваши генерации закончатся через 2 дня. Докупить?"

**Настройки:** клиент выбирает частоту (ежедневно / 3 раза в неделю / только важное / никогда)

### 4.3 AI-ассистент в каждом табе
- **В планировщике**: "AI, заполни календарь на неделю" → OMEGA генерирует 7 постов
- **В аналитике**: "Почему просмотры упали?" → AI-анализ + рекомендации
- **В чате**: @omega в любой момент
- **В настройках**: "AI, помоги настроить профиль" → пошаговый wizard

## 8. 🔄 УПРАВЛЕНИЕ ПОДПИСКОЙ КЛИЕНТОМ

### 8.1 Self-Service портал
Клиент может без помощи support:
- Посмотреть текущий тариф и лимиты
- Изменить тариф (upgrade/downgrade)
- Применить промокод
- Докупить аддоны
- Настроить авто-продление
- Скачать инвойс
- Отменить подписку (с exit-опросом + персональным предложением)

### 8.2 Grace Period & Churn Prevention
- Подписка закончилась → 3 дня grace period (функции работают)
- День 1: "Ваша подписка истекла. Продлите сейчас — скидка 20%"
- День 2: "Не хотите терять прогресс? +7 дней бесплатно при продлении"
- День 3: "Последний день. Ваши данные сохранены 30 дней"
- OMEGA анализирует причины оттока и предлагает персональное решение

### 8.3 Pause (пауза подписки)
- Клиент может приостановить подписку на 7/14/30 дней (1 раз в квартал)
- Данные сохраняются, лимиты заморожены
- Авто-уведомление за 2 дня до окончания паузы
