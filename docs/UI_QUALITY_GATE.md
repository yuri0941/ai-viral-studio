# Гейт UI-качества «Не ИИ-вёрстка»

> [B4-DOP-2] Обязательный гейт сдачи для всех батчей, затрагивающих UI.
> Экран НЕ считается сданным, пока все 8 пунктов не пройдены и не приложены снимки.

## Чек-лист «идеальный кабинет» (8 пунктов)

1. **Esc закрывает каждую модалку.** Любое модальное окно/дровер закрывается по `Escape` без исключений.
2. **Focus-trap в модалках.** Фокус не уходит за пределы открытой модалки (`Tab`/`Shift+Tab` циклятся внутри); после закрытия фокус возвращается на триггер.
3. **Тултипы у всего обрезанного.** Любой текст с `text-overflow: ellipsis` / обрезкой имеет `title` или тултип с полным текстом.
4. **Стили только по дизайн-системе.** Никаких самодельных кнопок/инпутов/карточек вне дизайн-системы: только существующие компоненты и токены (цвета, радиусы, тени).
5. **Reduced-motion.** При `prefers-reduced-motion: reduce` анимации/транзишены отключены или сведены к мгновенным.
6. **Матрица адаптива.** 360 / 428 / 768 / 1280 / 1920 px × RU / EN: 0 горизонтальных скроллов, 0 налезаний, 0 обрезанного текста.
7. **First screen < 2с.** Первый экран кабинета отрисовывается быстрее 2 секунд (локальный прогон, без троттлинга сети).
8. **Empty-state — inline-контент, не блокировка.** Пустые состояния показывают подсказку/CTA прямо на месте контента, а не блокирующую заглушку или ошибку.

## Как прогонять

- Адаптив и налезания: `node scripts/ui-audit.mjs` (Playwright, матрица ширин).
- Точечные снимки: существующие скрипты `scripts/*shot*.mjs`, `scripts/qa-view-as.mjs`, `scripts/addons-editor-shots.mjs`.
- Esc / focus-trap / tooltips / reduced-motion — ручная проверка по пунктам 1–5 плюс поиск по коду (`Escape`, `prefers-reduced-motion`, `title=`).

## Сдача батча

К отчёту прикладываются: снимки 360 и 1280 (RU) каждого нового экрана и явная отметка по каждому из 8 пунктов.
