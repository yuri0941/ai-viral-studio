## Б. ЧТО ПРИСЫЛАТЬ КИМИ — МАТРИЦА ПО ТИПАМ ЗАДАЧ

> Золотое правило: **код бага + лог момента ошибки** — без этого диагноз будет гаданием. Для стратегии/планов код НЕ нужен — только отчёты.

| Тип задачи | Обязательно прислать | Не нужно |
|---|---|---|
| **Дебаг VK-публикаций** | `backend/services/vkPublishService.js`, `backend/services/platformPublisher.js`, `backend/routes/scheduledPosts.js`, `backend/models/ScheduledPost.js` + **логи Render ±50 строк вокруг попытки** | PROGRESS_REPORT целиком |
| **Дебаг подключения/ключей VK** | `backend/routes/vk.js`, `backend/utils/connectedSocials.js`, `backend/controllers/userController.js`, `backend/models/User.js` + логи | Фронтенд-файлы |
| **Дебаг платежей (ЮKassa)** | `backend/routes/payments*.js`, `backend/services/paymentService.js`, webhook-обработчик + логи webhook'а | Соцсети |
| **Планировщик / композер (фронт)** | `frontend/src/pages/SchedulerPage.jsx`, `frontend/src/services/api.js` + скрин/описание бага | Backend-сервисы |
| **UI / i18n** | Компонент `.jsx` + `ru.json`, `en.json` | Логи Render |
| **Стратегия, приоритеты, планы** | `PROGRESS_REPORT.md` + дорожная карта | Код вообще |
| **Большой рефакторинг / новый эпик** | **ZIP всего репозитория** (без node_modules, dist, uploads) — лучший вариант | По одному файлу |
| **Логи Render** | Кусок ±50 строк вокруг события, текстом | Скриншоты (плохо читаются), весь лог за день |

**Форматы:**
- Файл > 1000 строк — можно присылать целиком, я дочитаю. PROGRESS_REPORT после внедрения гигиены (архив >30 дней) станет лёгким.
- Логи — текстом, не скринами.
- Если не уверен, что прислать — спроси в начале чата одной строкой: «какие файлы нужны для X?» — это дешевле, чем итерация вслепую.
