# Omega Agent — Ready to Use

## Что внутри
- `.env` — ваши API-ключи (10 провайдеров)
- `core/multi_agent.py` — агент с fallback-цепочкой
- `run.bat` — запуск на Windows (автоматически загружает .env)

## Запуск (3 шага)

```cmd
cd D:\kilo2\ai-viral-studio
:: Распакуйте архив в папку (например, tools\omega-agent)

cd tools\omega-agent
run.bat
```

Введите задачу — агент сам выберет рабочего провайдера.

## ⚠️ ВАЖНО — Смените ключи!

Эти ключи уже опубликованы в чате. **Смените их после первого запуска:**
1. Зайдите в консоль каждого провайдера
2. Revoke / Delete старые ключи
3. Создайте новые
4. Вставьте новые в `.env`

## Fallback-цепочка (приоритет)

1. Cerebras → 2. Groq → 3. DeepSeek → 4. Mistral → 5. Together → 6. Fireworks → 7. Novita → 8. DeepInfra → 9. Cloudflare → 10. OpenRouter

Если один падает — автоматически переключается на следующий.

## Workflow с Kimi

1. Агент делает задачу → пишет отчёт в `agent-reports/`
2. Вы копируете отчёт → вставляете Kimi в чат
3. Kimi проверяет → даёт следующий промпт
4. Вы вставляете промпт в агента
